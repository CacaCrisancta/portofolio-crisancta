PAKET INTEGRASI DOKUMEN — CACA PERSONAL PORTFOLIO

CARA MEMASANG
1. Ekstrak seluruh isi ZIP ini ke folder utama CACA PERSONAL PORTFOLIO,
   yaitu folder yang berisi index.html dan folder images.
2. Jika Windows menanyakan penggantian file, pilih Replace untuk index.html.
3. Jangan hapus folder images atau file model .MOD yang sudah ada.
   Paket ini hanya memperbarui index.html dan menambahkan tiga PDF.
4. Jalankan kembali melalui Live Server atau lakukan redeploy website.

FILE YANG DITAMBAHKAN / DIPERBARUI
- index.html
- berkas-cv/CV_REGULER_CACA.pdf
- project-files/TUGAS_BESAR_PPD.pdf
- project-files/LAPORAN_AKHIR_PRAKTIKUM_PPIC_CACA.pdf

FUNGSI YANG SUDAH DIHUBUNGKAN
- Tombol Download CV mengunduh CV REGULER CACA.pdf.
- Proyek Lampu Kamar Mandi Otomatis: View Report membuka TUGAS_BESAR_PPD.pdf;
  Download Report mengunduh file PDF yang sama.
- Proyek PPIC: View Report membuka laporan akhir praktikum PPIC;
  Download Report mengunduh PDF laporan asli, bukan PDF ringkasan buatan.
- Tautan dokumen tetap tersimpan setelah refresh melalui migrasi Local Storage.

CATATAN
File gambar, file .MOD, dan aset lain yang sebelumnya ada di folder website
harus tetap dipertahankan. Pastikan seluruh folder berada sejajar dengan
index.html sesuai struktur di atas.
